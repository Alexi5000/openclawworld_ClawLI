# Support

## Where to ask for help

Use the [GitHub issue tracker](https://github.com/Alexi5000/openclawworld_ClawLI/issues) for reproducible local setup problems, documentation corrections, and requests related to this fork’s agent-engineering guidance. Please include your operating system, Node.js and npm versions, the affected package (`client`, `server`, `landing-page`, or `packages/openclawworld`), and the exact command output.

## Upstream and fork-specific work

This repository is a fork of [DevvGwardo/openclawworld](https://github.com/DevvGwardo/openclawworld). Report defects that also affect the unmodified upstream project upstream when practical. Use this repository for Alexi5000-specific documentation, quality controls, operational guidance, and fork-maintained changes. See [FORK_POLICY.md](FORK_POLICY.md) for the maintenance boundary.

## Security and private concerns

Do **not** use public issues for suspected vulnerabilities, exposed credentials, unsafe agent actions, or sensitive deployment details. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

## What support does not include

Maintainers cannot provide hosted service guarantees, third-party provider account support, or recovery of credentials. This project is intended for local development, controlled self-hosting, and trusted-community experimentation; review the security guidance before exposing a deployment publicly.
